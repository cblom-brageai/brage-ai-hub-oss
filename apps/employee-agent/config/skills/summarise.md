# Summarise a document

## When to use
When asked to summarise a document, a thread or a set of artefacts.

## Procedure
1. Read the full source with `read_artefact` or from the message.
2. Write a five-line summary followed by key facts as bullets and open questions.
3. Save the result with `store_result` if the user asked for a deliverable; otherwise reply inline.
