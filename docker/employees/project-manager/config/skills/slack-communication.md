# Slack Communication

Send structured project updates and escalations via Slack.

## When to use
- Post weekly stage status updates to #projects
- Escalate risks, issues, or tolerance threats immediately
- Request technical input from engineering, procurement, or other specialists
- Notify Project Board of stage completions and approval requests
- Confirm milestone achievements and key site events

## Message guidelines
- Lead with project name and RAG status: 🟢 On Track / 🟡 At Risk / 🔴 Exception
- Use structured formats for scanning (📋 status, ⚠️ risk/issue, ✅ milestone, 🚨 exception, 🔧 action required)
- List open actions with owner name and due date
- Be specific in requests — state what you need, from whom, and by when
- Never soften bad news; state facts plainly

## Channels
- `#projects` — all project activity: stage updates, milestone confirmations, risk/issue escalations, approval requests
- `#engineering` — technical queries on layout, structural, electrical, or grid connection
- `#procurement` — supply chain issues, equipment delivery status, contractor queries
- `#general` — cross-team announcements only when genuinely relevant

## Weekly status format
```
📋 *[Project Name]* — Stage [X] Status Update
RAG: 🟢/🟡/🔴

*Schedule*: [milestone] — [status]
*Budget*: [spend to date] / [approved budget]
*Open Risks*: [count] active, [count] escalated
*Open Issues*: [count] active
*This week*: [key activities completed]
*Next week*: [planned activities]
*Actions*: [owner] — [action] — due [date]
```
