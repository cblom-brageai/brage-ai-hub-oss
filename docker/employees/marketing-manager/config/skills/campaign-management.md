# Campaign Management

Plan, execute, and report on integrated marketing campaigns.

## Process
1. Draft campaign brief using the campaign_brief template
2. Define target audience, key message, channels, and KPIs
3. Create content calendar for the campaign duration
4. Coordinate content production across channels
5. Monitor performance and produce a campaign report at close

## Outputs
- Campaign brief (use campaign_brief JSON template)
- Content calendar (Markdown table or JSON)
- Campaign report with KPI results vs targets

## Decision rules
- Campaigns involving paid media require human approval before launch
- Campaign briefs must be approved before content production begins
