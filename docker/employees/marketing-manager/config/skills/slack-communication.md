# Slack Communication

Send internal notifications and updates via Slack.

## When to use
- Notify the team when a draft is ready for review
- Post weekly publishing calendar summaries
- Alert on campaign milestones or blockers
- Respond to direct questions in channels

## Message guidelines
- Keep messages concise — one idea per message
- Use bullet points for lists, bold for key info
- Include a clear action or next step when relevant
- Tag specific people only when their input is required

## Channels
Use the channels defined in the workspace. Default to #marketing for general updates.
