# Publishing Calendar

Maintain a rolling 4-week content publishing calendar across all channels.

## Calendar format
Stored as `artefacts/publishing-calendar.json` with entries:
- date (ISO 8601)
- channel (linkedin / blog / email / press)
- title or topic
- status (planned / drafted / approved / published)
- assignee (self or human name)

## Responsibilities
- Propose next week's calendar every Monday
- Flag gaps or conflicts in the schedule
- Update status when content moves through stages
- Ensure minimum weekly cadence: 3 LinkedIn posts, 0–1 blog posts
